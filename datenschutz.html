Anwendung „FSA Backup“

FSA Backup ist eine private Anwendung. Sie wird ausschließlich vom Inhaber (Patrick Feierabend) für eigene Zwecke genutzt: Sie legt Sicherungen der eigenen Server im eigenen Google-Drive-Konto ab. Es gibt keine weiteren Nutzerinnen oder Nutzer.

  • Die Anwendung nutzt ausschließlich den Google-OAuth-Scope drive.file. Damit greift sie nur auf Dateien zu, die sie selbst in Google Drive angelegt hat.
  • Sie liest keine anderen Inhalte in Google Drive, keine E-Mails und keine Kontakte.
  • Die gespeicherten Daten sind Sicherungen, die bereits vor dem Hochladen verschlüsselt werden.
  • Es gibt keine Weitergabe an Dritte, keine Werbung und keine Analyse oder Auswertung von Daten.

Die Verwendung von Informationen, die über Google-APIs empfangen werden, erfolgt gemäß der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Widerruf

Der Zugriff der Anwendung lässt sich jederzeit in den Einstellungen des Google-Kontos widerrufen („Sicherheit“ → „Drittanbieter-Apps mit Kontozugriff“, myaccount.google.com/connections).
